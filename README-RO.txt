MATI MARKET – VERSIUNEA NOUĂ v4

Aplicație separată; nu suprascrie aplicația veche.

Modificări:
- Rezultatele căutării și catalogului revin la afișarea simplă, fără chenare cu scroll interior.
- Cantitate opțională, text liber (ex.: 1 bax, 2 bidoane, 5 kg); se preia imediat când apeși ADAUGĂ și poate fi modificată ulterior în listă.
- PDF reparat: structură PDF validă, cu paginare verificată și cantități vizibile.
- Cantitățile sunt afișate în PDF sub produs, cu eticheta CANTITATE: evidențiată și bold.
- Câmpul „Notă pentru comandă” este sub lista de produse; nota apare în partea de sus a PDF-ului.
- Butonul „Golește lista” cere confirmare explicită și șterge lista și nota; acțiunea poate fi anulată.
- Nota și cantitățile sunt salvate local și incluse în backup-ul JSON.

Publicare: încarcă toate fișierele din arhivă într-un repository GitHub separat de aplicația veche și activează GitHub Pages.
